        📲 홈 화면에 추가하는 방법

        아이폰 (iOS 16.4 이상)

        1. Safari로 이 앱 주소를 열어요
        2. 아래쪽 공유 버튼(네모에 화살표 ⬆️)을 눌러요
        3. 홈 화면에 추가를 누르고 오른쪽 위 추가를 눌러요
        4. 홈 화면에 생긴 할 일 달력 아이콘으로 앱을 열어요
        5. 여기 알림 켜기를 누르고 허용을 눌러요

        안드로이드 (Chrome)

        1. Chrome으로 이 앱 주소를 열어요
        2. 오른쪽 위 ⋮ 메뉴 → 홈 화면에 추가 (또는 앱 설치)
        3. 홈 화면 아이콘으로 앱을 열고, 알림 켜기 → 허용을 눌러요
